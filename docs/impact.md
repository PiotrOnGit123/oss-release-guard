# Ecosystem impact evidence

OSS Release Guard is a new project. Measured adoption and maintainer time savings are not yet established. Repository ownership does not make its owner a maintainer of PostgreSQL, OpenSSL, or another upstream project.

Record verifiable evidence as it becomes available. Keep private organizations and identities confidential unless publication is authorized.

| Evidence | Record to collect |
| --- | --- |
| Compatibility | Exact artifact version, trusted source, command, tool revision, and audit result. |
| Downstream use | Public integration link and confirmation from its maintainer. |
| Maintenance work | Linked issue, review, merged contribution, or published release. |
| Time saved | Measurement method, baseline, sample size, and limitations. |
| Security benefit | Reproducible finding and responsible disclosure record. |

No adoption entries have been recorded here. A compatibility example demonstrates a tested input, not an upstream endorsement or deployment.

Applications to support programs should describe actual contributions and cite this evidence. Program eligibility is determined by the program's criteria and reviewers.
